# granjero motion library

Generated by `webots-agri/tools/prepare_human_motions.py` (cut, heading-normalised, loop-detected, speed / yaw rate
measured). Do not edit the `.bvh` files by hand; re-run the tool.

| Clip | Source | What it is |
|---|---|---|
| `idle` | CMU 111_28 "Standing still" | standing in place (loop) |
| `walk` | Webots `walk.bvh` (cgspeed CMU) | walking cycle (loop), 1.17 m/s |
| `turn_left` / `turn_right` | CMU 69_16 / 69_18 "turn in place" | stepping on the spot (loop); the turning is done by the Robot node at the measured rate |
| `pick` | CMU 111_17 "Pick up" | bend down, pick something from the ground, stand up |
| `harvest` | CMU 14_20 "reach up, bend over" | reach up into the canopy, lower to a basket (loop) |
| `sit_down` / `stand_up` | CMU 111_06 "Get up from floor" (reversed / forward) | sit down on the ground / get up |
